## Featured project

### Cham Orders API

Production-style order management REST API built with Java 21, Spring Boot, PostgreSQL, Flyway, Docker and OpenAPI.

[View repository](https://github.com/Aslannt/cham-orders-api)

Key capabilities:

- JWT authentication.
- ADMIN and OPERATOR authorization.
- Customer, product and order management.
- Server-side monetary calculations.
- Historical product snapshots in orders.
- Domain, request and database monetary limits.
- PostgreSQL 17 and Flyway migrations.
- Docker Compose environment.
- OpenAPI JSON, YAML and Swagger UI.
- Correlation ID propagation.
- Standardized HTTP error contracts.
- 38 automated tests.
- Reproducible Docker-backed smoke test.

**Status:** Release Candidate
